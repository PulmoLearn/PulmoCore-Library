Acid-Base Interpretation

Use pH, PaCO₂, and HCO₃⁻ in a consistent order to identify respiratory and metabolic acidosis/alkalosis, recognize compensation, and spot obvious mixed disorders.

2027 RTEI.D.5 Evaluate blood gas resultsShared: I.C.5 Blood gas analysis
1. pHAcid or alkaline?
2. PaCO₂Respiratory direction?
3. HCO₃⁻Metabolic direction?
4. ComparePrimary, compensation, or mixed?
Socratic interpretation string

Build the sequence one decision at a time

Use the same order every time: pH → PaCO₂ → HCO₃⁻ → compensation/mixed check.

Core interpretation framework

Use direction, not memorized labels

Normal ranges: pH 7.35–7.45 • PaCO₂ 35–45 mmHg • HCO₃⁻ 22–26 mEq/L.

Respiratory componentPaCO₂ changes in the opposite direction from pH: high CO₂ pushes acidic; low CO₂ pushes alkaline.
Metabolic componentHCO₃⁻ changes in the same direction as pH: low bicarbonate pushes acidic; high bicarbonate pushes alkaline.
CompensationThe secondary system moves in the direction that brings pH back toward normal. Compensation does not create an overcorrection past normal by itself.
Obvious mixed disorderIf PaCO₂ and HCO₃⁻ are both pushing pH in the same abnormal direction, both processes are primary rather than one compensating for the other.
Fast rule

ROME: Respiratory Opposite, Metabolic Equal. Use it as a direction check—not as a substitute for reading the whole ABG.
