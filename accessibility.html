1. Our Commitment

PulmoLearn is committed to providing an educational experience that is accessible to as many learners as possible, including people with disabilities.

Accessibility is considered as we design, develop, review, and update PulmoLearn lessons, competency resources, interactive activities, assessments, simulations, dashboards, and other educational content.

Our goal is to make PulmoLearn content perceivable, operable, understandable, and robust so learners can access educational materials using a variety of devices, browsers, input methods, and assistive technologies.

2. Accessibility Standards

PulmoLearn aims to follow recognized digital accessibility standards and best practices, including the Web Content Accessibility Guidelines (WCAG) 2.2, Level AA.

We also consider accessibility practices associated with Section 508 of the Rehabilitation Act when designing and reviewing digital educational content.

These standards guide decisions related to navigation, keyboard access, color contrast, text alternatives, document structure, interactive activities, multimedia, forms, and compatibility with assistive technology.

Because PulmoLearn is continuously expanding and includes interactive educational experiences, accessibility is treated as an ongoing process rather than a one-time certification.

3. Accessibility Features

PulmoLearn incorporates accessibility features throughout the platform where appropriate. These may include:

  • Keyboard navigation — interactive controls are designed to be accessible without requiring a mouse whenever technically feasible.
  • Visible keyboard focus — links, buttons, and interactive elements include visible focus indicators.
  • Semantic page structure — headings, lists, navigation regions, buttons, and other elements are structured to support screen-reader navigation.
  • Text alternatives — meaningful instructional images and graphics are provided with alternative text or equivalent descriptive content when appropriate.
  • Decorative image handling — decorative graphics are identified so they do not unnecessarily interrupt screen-reader navigation.
  • Color contrast — text and interface elements are designed with contrast and readability in mind.
  • Information beyond color alone — important instructions, answers, alerts, or statuses are not intentionally communicated solely through color.
  • Readable typography — PulmoLearn uses highly legible fonts, responsive text sizing, and layouts designed for readability.
  • Responsive layouts — content is designed to adapt across desktop, tablet, and mobile screen sizes.
  • Reduced motion support — where supported, interfaces respect user preferences for reduced motion.

4. Learning Content & Interactive Activities

PulmoLearn includes interactive educational experiences such as case studies, competency activities, clinical simulations, sequencing exercises, hotspots, quizzes, and other practice activities.

We work to ensure that learners can understand and complete these experiences without relying exclusively on visual presentation, precise pointer movement, color recognition, or other single methods of interaction.

Depending on the activity, accessibility features may include:

  • Keyboard-accessible controls and answer selections
  • Screen-reader labels and instructions
  • Alternative text or descriptions for clinical images
  • Text-based feedback accompanying visual feedback
  • Logical reading and focus order
  • Clearly labeled buttons, fields, and navigation controls
  • Instructions that do not depend solely on shape, color, or location

Some clinical learning activities necessarily involve interpreting visual information such as radiographs, waveforms, ventilator graphics, anatomical images, or patient assessment findings. When visual interpretation is itself part of the learning competency, PulmoLearn aims to provide appropriate context and accessible supporting information without removing the educational objective being assessed.

5. Assistive Technology & Browser Support

PulmoLearn is designed using standard web technologies intended to support modern browsers and commonly used assistive technologies.

Users may access PulmoLearn using tools such as:

  • Screen readers
  • Keyboard-only navigation
  • Browser zoom and text enlargement
  • Operating-system magnification tools
  • Speech recognition and alternative input tools
  • High-contrast and display customization settings

For the best experience, we recommend using a current version of a modern web browser. Older browsers or outdated assistive technology may not support all accessibility features available through current web standards.

6. Third-Party Content

Some PulmoLearn content or functionality may rely on third-party platforms, embedded media, learning management systems, payment processors, authentication providers, or other external services.

We work to select services that support accessible experiences when practical. However, PulmoLearn does not control the accessibility of websites, applications, or interfaces operated by third parties.

If a third-party component creates an accessibility barrier while you are using PulmoLearn, please contact us so we can help identify an alternative way to access the relevant educational information when reasonably possible.

7. Known Limitations

PulmoLearn contains a growing library of educational content and interactive learning activities. Although accessibility is incorporated into our development and review process, some content may not yet fully meet every accessibility guideline in every combination of browser, device, and assistive technology.

Areas that may require additional accessibility consideration include complex clinical diagrams, interactive simulations, drag-and-drop activities, embedded third-party media, and educational activities where interpretation of visual clinical information is part of the learning objective.

We review these experiences as the platform develops and work to provide keyboard alternatives, text equivalents, accessible instructions, or other reasonable alternatives when appropriate.

If any PulmoLearn feature prevents you from accessing required educational content, please contact us. We want to know where barriers exist so we can evaluate and address them.

8. Accessibility Feedback & Assistance

We welcome feedback from learners, educators, and other users about the accessibility of PulmoLearn.

If you encounter an accessibility barrier, please email hello@pulmolearn.com.

When possible, please include:

  • The page, lesson, or activity where the issue occurred
  • A brief description of the accessibility barrier
  • The browser or device you were using
  • The assistive technology being used, if relevant and if you are comfortable sharing that information

Providing this information is optional, but it can help us identify and address the issue more effectively.

We will make reasonable efforts to provide access to the affected educational content while accessibility concerns are being evaluated.

9. Ongoing Improvement

Accessibility is part of PulmoLearn's ongoing design and development process. As existing lessons are revised and new courses, simulations, and learning tools are created, we continue to evaluate accessibility alongside instructional quality and clinical accuracy.

Our accessibility efforts may include:

  • Reviewing new and updated learning content
  • Improving keyboard navigation
  • Adding or refining alternative text
  • Improving screen-reader labels and announcements
  • Reviewing color contrast and focus indicators
  • Improving accessible alternatives for interactive activities
  • Responding to accessibility feedback from users
  • Updating practices as accessibility standards evolve

We may update this Accessibility Policy as PulmoLearn's platform, content, technology, or accessibility practices change.
