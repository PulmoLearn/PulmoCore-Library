Faculty Setup Guide

Add PulmoLearn Lessons to Your Canvas Course

This guide walks instructors through the one-time PulmoLearn LTI installation and the repeatable workflow for creating PulmoLearn assignments in Canvas.

One-time setup Add the PulmoLearn LTI app to each Canvas course.
Repeat for each lesson Create the assignment, paste the PulmoLearn HTML, and select the lesson.
Automatic completion PulmoLearn sends completed lesson status back to Canvas.
Part 1

Add the PulmoLearn LTI App

Complete this once for each Canvas course before adding PulmoLearn assignments.

One-time course setup: Once PulmoLearn appears as an External Tool in the course, you do not need to repeat this step for every assignment.
1

Open the Canvas app configuration

Install PulmoLearn at the course level using the provided Client ID.

  1. Open the Canvas course.
  2. Select Settings from the course navigation.
  3. Open the Apps tab.
  4. Select View App Configurations.
  5. Select + App.
  6. Choose the configuration option that uses a Client ID.
  7. Enter the PulmoLearn Client ID below.
  8. Follow the Canvas prompts to install or enable PulmoLearn for the course.
Settings → Apps → View App Configurations → + App → By Client ID

Part 2

Create a PulmoLearn Assignment

Repeat these steps for each PulmoLearn lesson you want to place in a Canvas module.

1

Create the assignment from Modules

Build the assignment where students will encounter it in the course.

  1. Open the appropriate Module.
  2. Select the module + button.
  3. Choose Assignment.
  4. Select Create Assignment.
  5. Enter the PulmoLearn lesson name as the assignment name.
  6. Select Add Item.
Modules → + → Assignment → Create Assignment → Add Item
2

Edit the assignment and enter points

Open the assignment settings before connecting the External Tool.

  1. Open the new assignment.
  2. Select Edit.
  3. Enter the desired number of Points.
3

Paste the PulmoLearn assignment HTML

Use the PulmoLearn Assignment Builder to create the branded Canvas instructions.

  1. In the Canvas assignment description, select the </> HTML Editor.
  2. Open the PulmoLearn Assignment HTML Builder.
  3. Select the correct Course.
  4. Select the correct Lesson.
  5. Use Copy Canvas HTML.
  6. Return to Canvas and paste the HTML into the assignment HTML editor.
Open Assignment HTML Builder
Edit Assignment → </> HTML Editor → Paste PulmoLearn HTML
4

Choose PulmoLearn as the Submission Type

Connect the Canvas assignment to the LTI External Tool.

  1. Scroll to Submission Type.
  2. Select External Tool.
  3. Select Find.
  4. Choose PulmoLearn from the External Tools list.
Submission Type → External Tool → Find → PulmoLearn
5

Select the PulmoLearn course and lesson

The PulmoLearn picker filters the lesson list by course.

  1. In the PulmoLearn External Tool window, select the appropriate Course.
  2. Select the matching Lesson.
  3. Verify the displayed lesson title and description.
  4. Select Add to Canvas.
PulmoLearn → Course → Lesson → Add to Canvas
6

Save and publish

Finish the assignment and make it available to students.

  1. Confirm the PulmoLearn External Tool appears in the assignment settings.
  2. Review the points and assignment description.
  3. Select Save & Publish.
Review → Save & Publish

What Students Experience

Students launch the lesson from the Canvas assignment. PulmoLearn verifies their account access, opens the assigned lesson, saves progress, and returns completion to Canvas when the lesson reaches 100%.

1. Open Canvas assignment
2. Launch PulmoLearn in a new window
3. Sign in if prompted
4. Complete the assigned lesson
5. Return to Canvas and use “Check My Completion” if the status has not refreshed yet
